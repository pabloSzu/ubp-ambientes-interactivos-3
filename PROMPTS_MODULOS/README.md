# Prompts por modulo

Carpeta con un prompt listo para pegar en una IA por cada modulo de la materia.

Cada prompt pide generar 4 documentos separados:

- CONTENIDO
- GLOSARIO
- OBJETIVOS
- ACTIVIDADES

La regla principal queda repetida dentro de cada prompt: el contenido teorico no debe mezclar quizzes, juegos ni simuladores. Todo lo interactivo va exclusivamente en ACTIVIDADES.
