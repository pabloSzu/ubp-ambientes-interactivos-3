# UBP - Programacion para Ambientes Interactivos III

Repositorio de trabajo para la materia **Programacion para Ambientes Interactivos III**.

La version web de la materia vive en:

```text
Materia_Web/
```

Entrada principal:

```text
Materia_Web/index.html
```

## Vista local

Desde la raiz:

```powershell
python -m http.server 8124 --directory Materia_Web
```

Luego abrir:

```text
http://localhost:8124/index.html
```

## Estructura

- `principal.pdf`: programa formal.
- `Programación para Ambientes Interactivos III- Contenido y Módulos.pdf`: contenidos y modulos formales.
- `DOCUMENTO_MAESTRO_MATERIA.md`: criterio pedagogico y reglas de construccion.
- `Materia_Web/`: producto web para estudiantes.
